Ustawienia

Klucz API Pl@ntNet

Darmowy (500 rozpoznań dziennie). Załóż konto na my.plantnet.org, skopiuj klucz i wklej tutaj. Klucz jest zapisywany w Twojej chmurze Supabase, więc działa na wszystkich zalogowanych urządzeniach.

Bezpieczniejszy wariant produkcyjny: skonfiguruj Supabase Edge Function jako proxy do Pl@ntNet i trzymaj sekret po stronie funkcji, żeby nie był widoczny w przeglądarce.
